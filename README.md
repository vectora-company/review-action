# Review Action

This repository retains a GitHub Composite Action, but the Action is inactive.
It does not inspect pull requests, call external services, or publish comments.

## Use

Invoking the Action only emits a warning. It has no inputs, outputs, secrets,
or network requirements.

## Development

Validate changes to action.yml with actionlint. See
[CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md).
